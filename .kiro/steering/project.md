
# Project: Expense & Budget Visualizer

## Overview
A mobile-friendly expense tracking web application that helps users record daily expenses, view total spending, and understand spending distribution by category.

## Tech Stack
- HTML for page structure
- CSS for styling
- Vanilla JavaScript for application logic
- Browser Local Storage API for saving transactions
- HTML Canvas API for drawing the pie chart
- No frameworks and no backend

## Required Features
- Transaction form with Item Name, Amount, and Category
- Categories: Food, Transport, and Fun
- Validate all required fields
- Display transactions with name, amount, and category
- Delete transactions
- Automatically update total expenses
- Pie chart showing spending distribution by category
- Persist transactions using localStorage

## Optional Features
- Monthly spending summary
- Sort transactions by date
- Dark and light mode toggle

## File Structure
- index.html: main application page
- css/style.css: application styles
- js/script.js: application logic and chart rendering
- .kiro/steering/project.md: project guidance

## Constraints
- Use only HTML, CSS, and Vanilla JavaScript
- Keep exactly one CSS file inside css/
- Keep exactly one JavaScript file inside js/
- Keep the interface clean, responsive, and accessible
- Store transaction data in browser localStorage
- Ensure the application works in modern browsers
